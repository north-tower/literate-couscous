Sending behavior

How Sendline sends messages

Sendline does not enforce daily or weekly caps. Each message is composed and sent the way a person would: open a new message, find the recipient, type the text, send, then pause before the next person.

What the worker does

Opens LinkedIn’s new-message window for each person on your list.

Types the recipient name at human speed, then selects the match.

Types your template (with {name} filled in) character by character — not instant paste.

Waits a moment, clicks Send, then pauses roughly 16–42 seconds before starting the next person.

Long lists run until you stop the campaign or LinkedIn shows an account restriction. Sendline does not automatically stop with a “come back tomorrow” message.

90-day memory

When a message sends successfully, that person is recorded for 90 days. Re-running the same list skips anyone already messaged in that window so you do not double-send.

Failed or skipped attempts do not count toward that memory.

LinkedIn limits

LinkedIn may still restrict an account if activity looks automated or too heavy. If Sendline detects a limit message in Chrome, the run stops immediately.

Slower, human-like sending reduces risk but does not guarantee compliance with LinkedIn’s User Agreement.
