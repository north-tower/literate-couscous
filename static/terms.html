Sending terms

How fast Sendline is allowed to send

LinkedIn does not publish a safe number of ordinary messages per day. Accounts get restricted when too many messages go out too quickly. These are the caps Sendline enforces so a long list is spread across days.

Careful is the default. Use Established account only for an older LinkedIn login that already messages people in the normal course of work.

The two paces

Limit Careful Established account
Per day 20 35
Per week 80 120
Per hour 8 12
Gap between messages 2–4 minutes About 1.5–3 minutes

The day resets at local midnight. The week resets on Monday at local midnight. The hour is a rolling hour, not the clock hour. The gap is a random wait inside that range, so messages are not sent on a fixed beat.

What happens on a long list

Sendline sends until the next message would pass a cap, then closes Chrome and stops. The log says when sending can continue. Press Start again after that time. People already messaged in the last 90 days are skipped, so the same list continues instead of sending twice.

If the hourly cap is hit and the next message is less than 20 minutes away, the run waits and then continues. If the wait is longer, Chrome closes so the session is not left open.

A message that does not send does not count toward the caps. If LinkedIn shows an account limit, the run stops immediately.

What these terms do not do

LinkedIn’s weekly invitation limit is a separate control, and it varies by account. These caps cover ordinary messages only.

Slowing the run lowers the chance of a restriction. It does not make automated messaging allowed under LinkedIn’s User Agreement, and it does not guarantee an account will stay unrestricted.
